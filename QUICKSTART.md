# Quick Start - 2 minutos

## Antes de usar

1. **Configure o AWS CLI** conforme [GITHUB_SETUP.md](GITHUB_SETUP.md).
2. **Garanta acesso ao Athena** no banco `db_conceito_relacional`.
3. **Se precisar publicar no GitHub**, use o passo a passo de [GITHUB_SETUP.md](GITHUB_SETUP.md).

---

## Usar no Copilot Chat

1. **Abra VS Code** neste diretório.
2. **Abra Copilot Chat**.
3. **Cole isto (início rápido):**

```text
Analise o banco db_conceito_relacional no Athena via AWS CLI.
Mostre um resumo das tabelas customers, orders, order_items, products e payments.
Depois execute uma consulta na vw_orders_customer_payment e traga 20 linhas.
```

4. **Aguarde a análise automática.**
